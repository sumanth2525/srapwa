# Placeholder for app icons and splash screens

This directory should contain the following assets for the PWA:

## Required Icons
- `icon.png` - 1024x1024 app icon
- `icon-192.png` - 192x192 icon for PWA
- `icon-512.png` - 512x512 icon for PWA  
- `adaptive-icon.png` - Android adaptive icon
- `favicon.png` - Browser favicon

## Splash Screens
- `splash.png` - App splash screen

## Screenshots (Optional)
- `screenshot-mobile.png` - Mobile screenshot for PWA manifest
- `screenshot-desktop.png` - Desktop screenshot for PWA manifest

For now, you can use placeholder images or generate them using:
- Expo's icon generator: `npx expo install expo-image-utils`
- Online PWA icon generators
- Design tools like Figma or Canva

The app will work without these assets, but they're required for a proper PWA experience.
